◆ 表示アプリ名
Hocotate-Tool-Kit

◆ カテゴリ
Pikmin Hack

◆ 概要
This application is a multi-purpose command-line tool for working with Nintendo GameCube / Wii archive and 3D model formats used in Pikmin 2.

◆ 詳細
It supports 14 conversion modes and accepts files via drag & drop, command-line arguments, or Windows right-click context menu. Dropping a BMD/BDL file runs all three BMD export modes at once (bmd2dae, bmd2fbx, bmd2obj) and places each output in a named subfolder next to the source file.
You can access various functions by right-clicking.

◆ 主な機能
・supports 14 conversion modes
・Conversion between BMD and FBX
・Extracting and Compressing SZS Files
・Extracting Disc Data from the GameCube and Wii
・Launching functions via right-click
